# Demonstração de formatos — Instagram

Conteúdo fictício (não publicado), gerado só para mostrar visualmente o que a pipeline já produz. Cada pasta é um formato:

- `post-artigo/` — carrossel de artigo (5 cards)
- `post-aviso/` — card único de aviso
- `post-curiosidade/` — card único "você sabia?"
- `post-citacao/` — card único de citação
- `stories-quiz/` — sequência de stories em vídeo, automática (pergunta no primeiro story, resposta no seguinte — sem sticker, sai pela API)
- `reel-cenas/` — reel feito do zero, com cenas
- `story-aviso/` — story em vídeo de divulgação de post novo (sai pela API)
- `story-video-novo-template/` — template genérico "VÍDEO NOVO NO CANAL" do story de vídeo novo: este é sempre postado manualmente, com o sticker de link do vídeo e o nome do canal (@pesquisaoperacionalparatodos) na faixa abaixo

Textos e dados são de exemplo, sem checagem de fato — o foco é só o visual.
